BlitzSMP VisualPack v4 + Cameras — Minecraft Java 26.3

Перенос выполнен с использованием локально установленных оригинальных
клиентов Minecraft 26.2 и 26.3. SHA-1 клиентских JAR проверен по данным
лаунчера. Старые архивы не изменялись.

Изменения:
- Формат пака: 97.1, Minecraft Java 26.3.
- Ванильная основа обновлена до оригинальных ресурсов 26.3.
- Устаревшие ванильные файлы 26.2, отсутствующие в 26.3, исключены.
- Сохранены модовые пространства имён, иконка, крепления шапок Create
  и все 20 файлов BlitzCameras.
- Дополнения Create объединены с актуальными атласами blocks и items.
- Палитры отделки брони переведены на идентификаторы палитр 26.3.
- Удалён устаревший atlas armor_trims; созданы 36 метафайлов палитр
  и 198 правил отделки для cardboard equipment.
- Обновлены 109 элементов моделей с устаревшим shade=false.
- Перенесены четыре модовых шейдера с импортами Mojang: #include,
  GLSL 330, явные номера входов и выходов.

Проверка реальными декодерами клиента Minecraft 26.3 без окна игры:
- Модели: 6596.
- Описания предметов: 2338.
- Атласы: 12.
- Описания экипировки: 48.
- Варианты четырёх обновлённых шейдеров, скомпилированные ShaderC: 16.
- Ошибки проверенной части: 0.
- Модовых описаний предметов, требующих своих типов/компонентов: 64.

Дополнительно: целостность ZIP, синтаксис JSON, ссылки на палитры,
родительские модели и ресурсы камер проверены. Ссылок на отсутствующие
родительские модели не найдено.

Установка: включи этот архив вместо старой версии. Отдельный пак камер
не требуется. Для серверной раздачи обнови URL и SHA-1.

Ограничения: визуальная проверка в окне игры и запуск с клиентскими
модами не выполнялись. Ресурс-пак не переносит исполняемый код модов;
для модовых механик и типов предметов нужны соответствующие моды
под Minecraft 26.3. Программы рендера Flywheel/Vanillin остаются
ресурсами этих модов и требуют проверки вместе с их версиями.
